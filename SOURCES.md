# Источники

- Население по районам на 01.01.2026 — официальная статистика (офстат).
- Оценка населения махаллей — модель на основе GHS-POP и зданий OSM,
  калибровка по районным итогам.
- Точки махаллей — слой `mahalla_points_2026` (EPSG:4326).
- Границы регионов (`data/regions/regions.geojson`) — Natural Earth, 10m admin-1, public domain. Граница Тошкент шаҳри в этом источнике не охватывает часть районов города (например, Яшнобод).
- Контуры махаллей (`data/polygons`) — файл `mahallalar_2026.geojson` (9 473 контура), переданный владельцем репозитория. Геометрия не менялась, файл только разложен по районам инструментом `tools/split_polygons.py`. Происхождение исходных границ в файле не указано; владелец репозитория подтвердил право публикации и сообщил, что границы махаллей — общедоступная информация.
- Район Чуст тумани (1714237) обновлён по этому же файлу: 71 махалля вместо 65, коэффициент калибровки 1,042786 вместо 1,129566, оценки пересчитаны. Шесть добавленных махаллей получили точки, вычисленные из контуров (точка внутри контура, как у остальных).
- Проверки: центроиды в `data/points` лежат внутри своих контуров, площади контуров совпадают с `area_km2` в пределах 1 %.
- Из файла контуров исключены две тестовые записи TEST (Олмазор тумани, № 2609059, 6 369 чел.; Яшнобод тумани, № 2608001, 1 417 чел.): их контуры лежали поверх настоящих махаллей других районов. Оценки остальных махаллей этих двух районов умножены на 1,015462 и 1,004486, `calibration_factor` умножен на те же коэффициенты, суммы районов равны официальным 418 300 и 317 200. `model_vs_official_gap` не пересчитывался.
