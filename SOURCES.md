# Источники

- Население по районам на 01.01.2026 — официальная статистика (офстат).
- Оценка населения махаллей — модель на основе GHS-POP и зданий OSM,
  калибровка по районным итогам.
- Точки махаллей — слой `mahalla_points_2026` (EPSG:4326).
- Границы регионов (`data/regions/regions.geojson`) — Natural Earth, 10m admin-1, public domain. Граница Тошкент шаҳри в этом источнике не охватывает часть районов города (например, Яшнобод).
- Контуры махаллей (`data/polygons`) — файл `mahallalar_2026.geojson` (9 473 контура), переданный владельцем репозитория. Геометрия не менялась, файл только разложен по районам инструментом `tools/split_polygons.py`. Происхождение исходных границ в файле не указано.
- Проверки: центроиды в `data/points` лежат внутри своих контуров, площади контуров совпадают с `area_km2` в пределах 1 %.
